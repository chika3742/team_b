## チームルール

- すべての変更は、mainブランチに直接コミット/プッシュせず、プルリクエスト（以下「PR」）を介して行います。
- プルリクエストは、発行者以外の1人の承認の後マージできます。マージ作業は発行者自身で行ってください。
